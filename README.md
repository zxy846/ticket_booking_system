Система бронирования авиабилетов

> Это внутренняя система продажи и управления билетами для авиакомпаний, разработанная с использованием Django, поддерживающая полный цикл управления рейсами, пассажирами и продажей билетов.

Введение в проект

Этот проект представляет собой веб-систему управления, разработанную для внутренних операций авиакомпаний, автоматизирующую процессы управления рейсами, управления информацией о пассажирах, продажи билетов и контроля доступа. Система использует управление доступом на основе ролей (RBAC), поддерживает работу пользователей с несколькими ролями и предоставляет интуитивно понятный интерфейс управления.

История разработки: Это был проект по разработке учебного курса для студентов факультета информационных и программных технологий [Название университета].

Функциональные модули

Аутентификация и контроль доступа

- Вход/выход пользователей и управление сессиями

- Ролевой контроль доступа (администратор, служба поддержки, обычные пользователи)

- Поддержка аутентификации с помощью JWT-токенов

Управление рейсами

- Операции CRUD для информации о рейсах

- Обновление статуса рейса в реальном времени

- Поиск по номеру рейса, аэропорту и времени

Управление пассажирами

- Управление персональной информацией пассажиров

- Поддержание контактной информации и идентификационных данных

- Просмотр истории заказов пассажиров

Управление билетами

- Онлайн-продажа билетов и распределение мест

- Запрос заказа, изменение расписания и отмена

- Управление ценами и статусом билетов

Панель управления бэкэндом

- Интеграция с Django Admin

- Визуализация данных и просмотр отчетов

- Настройка пользователей и разрешений системы

Технологический стек

- Бэкэнд-фреймворк: Django 4.x

- Фронтенд: HTML5, CSS3, JavaScript (нативный)

- База данных: SQLite3 (разработка)

- Аутентификация: Django Auth
